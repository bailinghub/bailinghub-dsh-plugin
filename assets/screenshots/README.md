# Marketplace screenshots

These images explain the public `dsh-bailinghub` flow with neutral demonstration data. They do not
contain a real BailingHub deployment, business identity, tenant, route, credential, authorization
code, employee record, or production payload.

The screenshots describe four verified product boundaries:

1. a local DeepSeek Harness Agent can use connected business capabilities;
2. the plugin is configured with four public connection fields and browser authorization;
3. the existing business identity, permission, and approval rules continue to apply;
4. BailingHub keeps the visible conversation and governed tool trajectory.

`marketplace.html` is the editable source. Render each `.shot` element at `1440 × 900` with a
Chromium-compatible browser after changing the copy. Keep the PNG filenames and
`../../screenshots.json` in sync.
